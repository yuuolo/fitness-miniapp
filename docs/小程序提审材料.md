## 二、功能介绍（可直接粘贴，125 字）

```
面向健身门店会员的工具：记录体测与力量成绩，按体脂率、相对力量、体重指数自动评分并生成排行榜；可参加门店竞赛、发布健身友圈动态（图文/视频）；会员之间可在教练裁判下发起 1v1 挑战，上传视频由教练判定胜负；支持记录日常运动、查看历史趋势与微信消息提醒。
```

## 四、审核员测试说明（直接复制）

```
测试账号：无需账号密码。

1. 打开小程序后用微信「一键登录」即可看到全部公开内容：
   首页 → 身体数据 → 力量排行榜 → 健身友圈 → 会员挑战。

2. 首页「会员挑战」为门店会员之间的 1v1 约战：
   - 发起挑战时必须指定一名教练担任主裁判；
   - 双方确认后各自上传 1 段视频；
   - 由教练判定胜负并填写判定理由；
   - 挑战结果对所有会员公开，可评论。
   审核时可浏览「挑战大厅」中已有内容，无需实际发起。

3. 员工工作台入口仅在角色为教练/管理员时显示，普通用户不显示，
   属于门店内部管理功能，不影响普通用户体验。

4. 「微信提醒」为微信订阅消息授权入口：用户点击后才订阅，
   用于接收友圈新视频、竞赛、排行榜更新等通知，不点则完全不受影响。

5. 本小程序不提供任何医疗诊断或治疗建议，体测/体脂数据仅供健身参考。
```

## 六、用户隐私保护指引（后台必须填写，否则会被驳回）

路径：小程序后台 → 设置 → 服务内容声明 → **用户隐私保护指引**

需要声明的信息类型（按实际勾选）：

| 信息类型 | 用途说明（可直接用） |
| --- | --- |
| 微信昵称、头像 | 用于展示会员在排行榜、友圈、挑战中的身份 |
| 手机号码 | 用于门店识别会员身份、联系会员 |
| 相册 / 摄像头 | 用于上传体测报告照片、健身动态图片与挑战视频 |
| 健康与运动数据（身高、体重、体脂、力量成绩、运动记录） | 用于计算身体评分、生成排行榜与历史趋势 |
| 设备信息（仅基础运行） | 用于保证小程序正常使用 |

**不收集**：位置信息、通讯录、剪切板、通话记录、相册全部照片（仅用户主动选择的文件）。

隐私政策链接 / 说明文案：

```
本小程序由门店运营，会员的体测数据、力量成绩、动态内容仅用于门店内部的健身管理与会员本人查看，
不会向第三方出售或共享。会员可随时联系门店删除自己的数据。
```

## 七、内容安全（UGC 说明，友圈/评论类容易问）

```
小程序内的会员动态（文字、图片、视频）与挑战评论属于用户发布内容，已提供以下管理能力：
1. 用户只能删除自己发布的内容；

3. 挑战视频由教练审核判定，作弊内容会被标记并公开；
4. 后台管理页面提供内容与媒体文件管理；
5. 若发现违规内容，可通过门店客服渠道反馈，24 小时内处理。
```

## 十一、常见驳回原因与对策

| 驳回理由 | 对策 |
| --- | --- |
| 功能不完整 / 白屏 | 检查服务器域名是否包含 `https://gym.novrein.com` 三类目；审核期间保持服务器在线 |
| 缺少用户隐私保护指引 | 后台「设置 → 服务内容声明」补全（第六节） |
| 涉及医疗健康需资质 | 强调"健身数据记录，不提供诊疗建议"，功能描述里加免责说明 |
| UGC 内容无审核机制 | 用第七节说明，并强调管理员可删除 |
| 类目与功能不符 | 确保勾选「体育 > 在线健身」，不要选医疗/社交类目 |
| 登录后无内容 | 正式库保持至少 5 条友圈、1 个竞赛、若干会员与成绩 |
| 员工入口让审核员困惑 | 用第四节第 3 点说明；或提审版本把员工入口放到「我的」最底部（已如此） |
