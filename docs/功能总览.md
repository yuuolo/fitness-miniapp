# 健身门店管理系统 · 功能总览

> 最后更新：2026-11-15 · 对应小程序版本 1.3.0
> 形态：微信小程序（自建 tabBar，22 个页面）+ 自建 Node/Express 后端 + PostgreSQL 16
> 部署：Ubuntu 24.04（4C/8G）Docker Compose，域名 https://gym.novrein.com

---

## 一、角色与权限

三级角色，权限向下包含：

| 角色 | 能力 |
| --- | --- |
| **会员** | 完善资料；看身体数据与力量排行榜；看/参加门店竞赛；发健身友圈；会员卡、团课、娱乐预约按开关启用 |
| **教练** | 会员的全部能力 + 搜索会员、查会员详情、录入身体数据与力量成绩、管理竞赛（发起/录成绩/传视频） |
| **管理员** | 教练的全部能力 + 代会员补充资料、设置角色、排行榜项目管理、首页布局、上传存储与功能开关 |

原「前台」角色已移除（v1.2.3），历史数据自动迁移为管理员。
权限矩阵实测脚本：`deploy/scripts/verify-roles.sh`

## 二、会员端（小程序）

### 1. 首页（可编排）

首页由**布局系统**驱动，每个角色一套模块顺序，管理员在后台拖拽编排：

- 6 种模块：欢迎 / 快捷入口 / 排行榜预览 / 竞赛预览 / 友圈预览 / 自定义快捷入口
- 可选页面白名单 14 个；每角色最多 20 个模块、8 个自定义入口
- 自定义入口可以自定义标题、说明、图标（**图标留空则不显示图标**）

### 2. 身体数据与力量成绩

- 体测数据：体重、体脂率、心率、肌肉量/率、蛋白质/率、体水分/率、骨盐量/率、
  脂肪量、骨骼肌量、内脏脂肪、腰臀比、身体年龄、骨骼肌指数、建议热量、
  基础代谢、去脂体重、身体得分、身体形态/类型、**节段脂肪五项 + 节段肌肉五项**
- 力量成绩：卧推 / 深蹲 / 硬拉（估算 1RM）
- 趋势图（条形，无图表库）
- **体测报告图片识别**（见第五节）

### 3. 力量排行榜

- 周榜 / 月榜切换
- 显示排名、成绩、我的名次
- 排行榜项目**可增删**：卧推/深蹲/硬拉三项受保护（只能隐藏不能删），
  其他自定义项目在「无任何成绩且无竞赛引用」时才允许删除

### 4. 门店竞赛

- 教练/管理员发起，设定时间范围、奖励奖品
- 参赛者实时排名与竞争数据
- 成绩可附视频，点击可看

### 5. 健身友圈

- 发照片/视频动态，点赞、评论、详情
- **所有登录用户都能看**（不设关注关系）
- 自动生成分享海报（含小程序码）

### 6. 会员卡（当前关闭）

- 我的会员卡、剩余次数、有效期
- 动态入场码（60 秒刷新），管理员扫码核验入场，次卡每天首次扣 1 次
- 开卡/调次/停卡/作废（后台能力，界面已下线）

### 7. 约课 / 娱乐预约（当前关闭）

- 团课与私教课预约、取消（开课前 2 小时内不可取消）
- 娱乐项目（攀岩/蹦床/台球等）按时段预约，到店付款

### 8. 我的

- 资料卡、身体数据入口、排行榜、竞赛、员工工作台（按角色显示）
- 积分展示（当前关闭）

## 五、体测报告图片识别（v1.3.0）

- 入口：会员详情 → 身体数据与力量成绩 → 「从体测报告识别」
- 支持小米八电极体脂秤（S800 等）的「人体成分分析报告」
- **一次识别约 3 秒，28 项指标自动填表**，教练核对后保存
- OCR **自建**：`deploy/ocr` 容器跑 RapidOCR（PP-OCR + onnxruntime，纯 CPU），
  不依赖云服务、无调用费用、数据不外传
- 关键难点：报告的脂肪/肌肉是左右并排两块，且「数值在部位名正上方」——
  按文字顺序必错，所以解析器用**词框坐标**做空间配对
- 兜底：识别不准时用微信「提取文字」粘贴解析
- 备用接入：`OCR_URL` 可指向腾讯云/百度/自建网关，返回结构自动兼容

## 六、功能开关（6 个）

| 开关 | 作用 | 当前 |
| --- | --- | --- |
| `cards` | 会员卡、入场码、扫码核验 | 关 |
| `classes` | 团课与私教课预约、排课、签到 | 关 |
| `venues` | 娱乐项目按时段预约与核销 | 关 |
| `moments` | 健身友圈 | **开** |
| `fitness` | 身体数据、力量成绩、运动记录 | **开** |
| `rank` | 排行榜与竞赛 | **开** |

- 由后端统一拦截（`ACTION_FEATURE`），关掉后接口直接返回「功能暂未开放」
- 小程序端隐藏入口、清空 tabBar 多余 tab
- 管理页可随时开关，5 秒缓存

## 七、数据与存储

**19 张表**：members / body_records / strength_records / activity_records /
moments / competitions / competition_entries / lift_items / member_cards /
card_types / card_logs / offline_payments / schedules / bookings /
venues / venue_slots / entry_logs / media / config

**上传存储**：三种驱动可切换（数据库 / COS / OSS），管理页可测试连通，
AccessKey 用 `CONFIG_SECRET` 加密后入库。

**通知**：微信订阅消息 3 个模板（预约成功 / 课前提醒 / 会员卡到期），
未配置模板 ID 时自动跳过，不影响业务。

**定时任务**：每 15 分钟——下课 30 分钟未签到记缺席（3 次封锁预约 7 天）、
会员卡到期提醒（夜间不发送、不重复发送）。
