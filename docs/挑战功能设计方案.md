## 二、微信消息通知（重点）

### 2.1 结论：能收到，但必须「用户点同意」

微信小程序给会员推消息只有一条正路：**订阅消息**，规则是：
- 用户**在小程序里点按钮时**弹一次授权框，同意后我们才能给他发 **1 条**
- 健身类小程序**拿不到「长期订阅」**（只有政务/医疗等特定类目有）
- 所以设计成：每次关键动作时顺手申请授权，之后发一条「该你了」的消息

### 2.2 已添加的模板（2026-11-18）

原模板库里已有：会员即将到期提醒、预约开始提醒、预约成功通知。
本次在「在线健身」类目下新增 3 个：

| 模板 | 用途 | 字段 |
| --- | --- | --- |
| **比赛邀请通知** | 有人向你发起挑战 / 你被指定为裁判 | 邀请人 · 比赛时间 · 比赛名称 · 参赛球队 · 比赛场地 |
| **挑战开始提醒** | 双方视频交齐，提醒裁判判决 | 挑战名称 · 挑战时间 · 温馨提示 |
| **对战结果通知** | 判定结果通知双方 | 活动名称 · 开始时间 · 结束时间 · 对战结果 · 温馨提示 |

模板 ID 已写进 `deploy/server/lib/templates.js`（可用环境变量覆盖）。

### 2.3 什么时候申请授权、什么时候发

| 用户动作 | 申请授权 | 之后能收到 |
| --- | --- | --- |
| 发起挑战 | invite + result | 对方应战、判定结果 |
| 被挑战者应战 | result | 判定结果 |
| 交视频 | result | 判定结果 |
| 裁判接单 | start | 双方交齐视频 → 「该判了」 |

发送时机（服务端）：创建挑战 → 通知对方 + 裁判；双方交齐视频 → 通知裁判；判定 → 通知双方。

> 注意：**用户不点同意就收不到**。这是微信的硬限制，不是我们代码的问题。
> 收不到也完全不影响挑战流程，页面红点、大厅角标照样能看。

### 2.4 代码位置

- `deploy/server/lib/templates.js`：3 个挑战模板配置
- `deploy/server/lib/challenge.js`：`notifyInvite / notifyJudgeReady / notifyJudgeResult`
- `miniprogram/utils/subscribe.js`：`wx.requestSubscribeMessage` 封装（3 秒超时兜底，绝不卡流程）
- 详情页、发起页：动作前调用 `subscribe.request([...])`

## 六、「有新变更就通知」会员（友圈视频 / 竞赛 / 两个排行榜）

### 6.1 做了什么

| 场景 | 触发时机 | 微信模板 |
| --- | --- | --- |
| **友圈有人发视频** | 动态里含视频时 | 学员作品发布通知 |
| **竞赛有变更** | 新建竞赛 / 竞赛结束或取消 | 赛事报名通知 |
| **综合评分榜变化** | 会员录了新体测、评分变动时 | 运动排行榜更新通知 |
| **力量排行榜变化** | 有人刷新某项目最好成绩时 | 运动排行榜更新通知 |

### 6.2 会员怎么订阅（统一入口 + 打开时提示）

**统一入口：我的 → 微信提醒**（各页面不再放订阅按钮）

- **一键订阅内容提醒**：一次点击同时授权「友圈新视频 / 竞赛动态 / 综合评分榜 / 力量排行榜」
  （两个排行榜共用同一个模板，所以 3 个模板一次授权覆盖 4 个话题）
- **挑战提醒**：同一页第二个按钮（有人挑战我 / 该我判了 / 判定结果）；
  也可以在发起挑战、应战、裁判接单时自动申请
- 页面显示每个话题还剩几条待发提醒，可单独清零
- **每次打开小程序**：如果还没有待发提醒，会自动弹一次「开启微信提醒？」的提示，点一下就订阅全部内容提醒（微信不允许全自动订阅，必须点一下才合法）；一天最多提示一次

微信限制（绕不过去）：
- **1 次授权 = 1 条消息**，所以每订阅一次只能收到下一次更新
- 票最多攒 5 张
- 发布人不会收到自己的更新
- 同一话题 30 秒内不重复群发（防刷屏）

### 6.3 技术细节

- 新表 `notify_subscriptions (openid, topic, tickets, updated_at)`
- 新 action：`notifyTopicTemplates`（下发模板 ID）、`subscribeTopic`（加票）、`mySubscriptions`（查票）
- 内部模块 `lib/notify-topics.js`：`broadcast` 群发 + 扣票；发送失败自动作废该票
- 触发点：`moment.js`（发视频）、`competition.js`（新建 / 结束）、`fitness.js`（力量成绩 / 体测评分）
