## 一、规则定稿

### 1.1 流程

```
① 发起：选项目 + 比法 + 指定一名教练当主裁判（必选）→ 2 小时内等对方应战
② 裁判接受 / 拒绝；被挑战者可以否决赛判（否决后发起人重选裁判）
③ 被挑战者应战 / 拒绝（超时 2 小时 → 失效）
④ 双方各自上传 1 段视频（教练可代传），应战后 2 小时内必须交齐
⑤ 视频交齐后 2 小时内主裁判判定：谁胜 / 谁负 / 平局，可标记某方视频作弊
⑥ 判定理由对所有会员公开；判定后 3 小时内可改判（留痕）
⑦ 作弊：该方判负 + 公开标记 + 记入作弊次数 + 禁赛
```

### 1.2 你定的 18 条

| # | 规则 | 定稿 |
| --- | --- | --- |
| 1 | 主裁判 | **只能是教练**（管理员可兜底判定） |
| 2 | 被挑战者否决赛判 | **可以**，否决后发起人重选 |
| 3 | 裁判拒绝接活 | **可以**，拒绝后发起人重选 |
| 4 | 改判窗口 | **判定后 3 小时**内 |
| 5 | 判定理由 | **对所有会员公开** |
| 6 | 视频 | **双方必须都传** |
| 7 | 视频数量 | 每人**最多 1 段** |
| 8 | 视频规格 | **沿用管理页的上传设定**（时长/体积，超时长自动裁切） |
| 9 | 作弊后果 | 判负 + 公开标记 + 累计作弊次数 + **禁赛** |
| 10 | 可见范围 | **所有会员可见** |
| 11 | 评论 | **先发后管**（管理员可删/隐藏） |
| 12 | 评论点赞 | **要** |
| 13 | 发到友圈 | **可以** |
| 14 | 三个时限 | 应战 **2h** / 视频 **2h** / 裁判判决 **2h** |
| 15 | 通知 | **红点 + 订阅消息 + 分享卡片** |
| 16 | 同时挑战数 | 每人最多 **2 场** |

### 1.3 我补的默认值（你没提，先这样定，随时可改）

| 项 | 默认值 |
| --- | --- |
| 作弊禁赛时长 | 每次 **7 天**；累计 **3 次**升级为 **30 天** |
| 视频没交齐 | 超过截止 → **流局**（不算胜负） |
| 裁判超时不判 | 状态停在「待判决」，**管理员可兜底判** |
| 挑战成绩 | 不自动写进力量排行（裁判判定为准，避免和成绩体系混在一起） |

## 二、数据模型

```sql
challenges          -- 挑战主体
  id, challenger, opponent, referee, lift_key, metric, trash_talk,
  status              -- pending 待应战 / waiting_referee 等裁判 / accepted 进行中
                      -- ready 待判决 / judged 已判定 / declined 拒绝 / expired 失效
                      -- void 流局 / referee_vetoed 裁判被否决
  referee_state       -- invited / accepted / declined
  judge_result        -- win_challenger / win_opponent / draw
  judge_note          -- 判定理由（对会员公开）
  judge_history jsonb -- 改判留痕
  judged_at, expire_at, submit_by, judge_by, created_at, finished_at

challenge_videos    -- 双方视频（每人 1 段）
  id, challenge_id, openid, video_url, video_thumb, uploaded_by,
  cheat_flag, cheat_reason, created_at

challenge_comments  -- 会员意见（P2 用，表已建）
  id, challenge_id, openid, content, like_count, status, created_at

members 新增
  challenge_cheat_count int   -- 作弊次数
  challenge_ban_until  bigint -- 禁赛截止
```

## 三、接口（已实现）

| action | 权限 | 说明 |
| --- | --- | --- |
| `createChallenge` | 会员 | 发起（必须选教练裁判、每人最多 2 场、禁赛者不可发起） |
| `pickReferee` | 发起人 | 裁判拒绝/被否决后重选 |
| `respondChallenge` | 被挑战者 | 应战 / 拒绝 / 否决裁判 |
| `refereeRespond` | 主裁判 | 接受 / 拒绝指派 |
| `submitChallengeVideo` | 双方或教练 | 交视频（每人 1 段；双方交齐 → 待判决） |
| `judgeChallenge` | 主裁判（管理员兜底） | 判胜负平 / 标作弊 / 写理由 / 3h 内改判 |
| `challengeList` | 会员 | 大厅（all / mine / incoming / judging） |
| `challengeDetail` | 会员 | 详情（含双方视频、判定理由、可操作标记） |
| `challengeSummary` | 会员 | 红点计数（待应战 / 待交视频 / 待判决） |
| `refereeOptions` | 会员 | 可选裁判（只列教练） |

**已实现的自动处理**：应战超时 → 失效；视频超时 → 流局；作弊 → 禁赛 + 累计；改判留痕。

**测试覆盖（已通过）**：发起校验（缺裁判/裁判非教练/裁判是当事人/挑战自己）、
公开可见、裁判拒绝与重选、被挑战者否决赛判、双方交视频、每人 1 段限制、
双方交齐进入待判决、非裁判不能判、判定理由公开、3 小时内改判留痕、
作弊判负+禁赛+累计、禁赛期间不能发起、同时最多 2 场、红点计数。

## 七、不做什么

- 不做金钱 / 实物赌注
- 不做自动判胜负（结果由裁判拍板）
- 不做实时直播
- 挑战成绩不自动计入力量排行（裁判判定为准）
